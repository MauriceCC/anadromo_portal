# Implementación de la web

Carpetas reservadas para componentes, layouts, páginas y estilos. No hay framework ni dependencias instaladas todavía.

Al implementar, elegir una solución adecuada para contenido mayormente estático y reutilizar los Markdown de `content/`. Definir explícitamente qué archivos se publican: excluir `incoming/`, plantillas, guías internas y secciones pendientes.

La dirección visual se encuentra en `docs/art-direction.md`; el mapa de contenido, en `docs/site-map.md`. Resolver las rutas de medios según la base de despliegue elegida, especialmente si se publica bajo una subruta.
